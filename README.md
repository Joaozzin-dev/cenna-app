🇧🇷 Sobre o Projeto
O Cenna não é apenas um rastreador de filmes; é uma rede social cinematográfica. Ele resolve a "fadiga da escolha" substituindo algoritmos genéricos por curadoria humana colaborativa.
✨ Diferenciais
 * Curadoria Colaborativa: Listas dinâmicas onde a comunidade injeta conteúdo.
 * Social-First: Críticas em texto, reviews em vídeo e enquetes interativas.
 * Experiência Fluida: Interface construída com foco em Glassmorphism e Haptics.
 * Arquitetura de Ponta: Um dos primeiros apps brasileiros a implementar React 19 e a Nova Arquitetura (Fabric/TurboModules) do React Native.
🇺🇸 About the Project
Cenna is a collaborative social ecosystem for cinema enthusiasts. It eliminates "choice fatigue" by replacing generic algorithms with human-driven curation and thematic social interaction.
✨ Key Highlights
 * Crowdsourced Curation: Dynamic lists where the community adds value.
 * Full Social Suite: Text reviews, video snippets, and interactive polls.
 * Premium UX: High-end UI featuring Blur effects and tactile feedback.
 * Cutting-Edge: Built on React 19 and the New Architecture, ensuring maximum performance.

🛠 Technical Highlights
Este projeto foi um desafio de engenharia focado em performance nativa.
 * Nova Arquitetura: Implementação de newArchEnabled: true, utilizando o motor de renderização Fabric.
 * Gerenciamento de Trabalho (Worklets): Uso intensivo de react-native-worklets-core para processamento em threads secundárias, garantindo 60fps constantes.
 * Integração Híbrida: Backend distribuído entre Supabase (PostgreSQL/Auth) e Firebase (Real-time features).
 * Type Safety: Detecção inteligente de metadados do TMDB para tratamento dinâmico de objetos Movie vs TV Show.
🚀 Setup
1. Requisitos
 * Node.js 18+
 * Expo CLI
 * Chaves de API (TMDB, Supabase, Firebase)
2. Instalação
# Clone
git clone https://github.com/joaozzin-dev/bros.git

# Instale (Obrigatório o uso de legacy-peer-deps devido ao React 19)
npm install --legacy-peer-deps

3. Variáveis de Ambiente (.env)
EXPO_PUBLIC_TMDB_API_KEY=sua_chave
EXPO_PUBLIC_SUPABASE_URL=seu_url
EXPO_PUBLIC_SUPABASE_ANON_KEY=sua_chave_anon
